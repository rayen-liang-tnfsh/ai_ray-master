# 高麗菜估價說明

## 目標
用 796 天的台北批發市場資料，預測高麗菜當天平均批發價（元/公斤），線性回歸的測試 Cost 目標越低越好。

## 使用的特徵（7 個）

| 特徵 | 意義 |
|---|---|
| `prev_price` | 昨天價格（價位水位，最重要） |
| `logvol` | log(今天交易量)：量多價低，相關 −0.86 |
| `dlogvol` | 量變化：今天比昨天多/少賣多少 |
| `logvol_x_prev` | 量 × 昨價：量的效果隨價位調整 |
| `dlogvol_x_prev` | 量變化 × 昨價 |
| `sin_m` / `cos_m` | 季節循環（月份放圓上） |

前處理：依日期排序 → 造特徵 → 剔除空白列（44 天）→ 隨機留 20%（153 天）當測試 → z-score 縮放（只用訓練資料算）。

## 為什麼不放的欄
- **天氣**（temp30、rain7）：控制季節後溫度相關只剩 +0.108；天氣的影響已經被交易量講完了，加了測試 Cost 差 0.38 < CV 標準差 2.4~4.5，是雜訊不是訊號。
- **年份**：會學到「每年跌 8 元」的假趨勢，時間切分下 Cost 爆到 90。
- **dprice**（昨天價差）：等於把今天答案偷給模型（資料洩漏），Cost 變 0 是假的。

## 成果

| 版本 | 測試 Cost |
|---|---|
| 最初版（logvol+天氣+年份+季節） | 27.849 |
| ＋前一天的價格 | 11.792 |
| ＋量變化與交互項（本版） | **10.003** |

Cost 單位是元²/公斤²；開根號約 4.47 元/公斤的平均預測誤差量級（相對均價 26 元約 17%）。

## 主要理由
1. **進步靠「想到還缺哪類資訊」，不是調參數**：價位水位（昨價）→ 供需變化（量變化）→ 效果隨價位調整（交互項）。
2. **量少的日子最難預測**：量 ≤ 10 噸的 18% 天數貢獻過半誤差，是線性模型的極限所在。
3. **只信超過雜訊的改善**：任何改動都用重複交叉驗證檢查，落在 ±0.14~0.17 內的差距一律視為雜訊，不宣告勝利。
